## Description
This web application is a static webpage that utilizes a JavaScript 3D Library to render an animation in the style of MadHouse, Inc. Every single graphic & sound effect was created by Claude, through code. 

## Demo
Deployed on Netlify: https://karakurenai.netlify.app/

## Features
* Static webpage deployed with Netlify
* Uses the Web Audio API to generate audio in the browser
* Responsive to mobile viewports
* Pause & Mute buttons
